# 🚀 Interactive Portfolio Website

A stunning, modern portfolio website showcasing 6+ years of software engineering experience. Built with React and featuring interactive animations, particle effects, and a sleek design.

## ✨ Features

- **Interactive Animations**: Smooth scroll effects, typing animations, and particle background
- **Custom Cursor**: Unique cursor experience for desktop users
- **Responsive Design**: Fully responsive across all devices
- **Modern UI/UX**: Gradient effects, glassmorphism, and smooth transitions
- **Performance Optimized**: Fast loading and smooth animations
- **SEO Ready**: Proper meta tags and semantic HTML

## 🎨 Design Highlights

- **Hero Section**: Dynamic typing animation showcasing multiple roles
- **Particle Canvas**: Animated particle network background
- **Timeline Experience**: Beautiful timeline layout for work history
- **Skill Cards**: Interactive hover effects on skill categories
- **Contact Cards**: Engaging call-to-action elements

## 🛠️ Tech Stack

- **React 18**: Modern React with Hooks
- **CSS3**: Custom animations and responsive design
- **HTML5 Canvas**: Particle animation system
- **Inter & Fira Code Fonts**: Professional typography

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📝 Customization

### Update Personal Information

Edit `src/App.js` to update:

1. **Skills**: Modify the `skills` object (line 28-36)
2. **Experience**: Update the `experiences` array (line 38-80)
3. **Contact Info**: Change email, LinkedIn, and GitHub links (line 457-478)

### Customize Colors

Edit `src/App.css` to change the color scheme:

```css
:root {
  --primary: #6366f1;
  --secondary: #ec4899;
  --accent: #8b5cf6;
  /* ... more variables */
}
```

### Add Your Photo

Replace the profile card section in the About component with your actual photo.

## 📦 Build for Production

Create an optimized production build:

```bash
npm run build
```

The build folder will contain optimized static files ready for deployment.

## 🌐 Deployment

This portfolio can be easily deployed to:

- **Netlify**: Drag and drop the `build` folder
- **Vercel**: Connect your GitHub repository
- **GitHub Pages**: Use `gh-pages` package
- **AWS S3**: Upload build folder to S3 bucket

### Quick Deploy to Netlify

1. Run `npm run build`
2. Drag the `build` folder to [Netlify Drop](https://app.netlify.com/drop)
3. Your site is live! 🎉
